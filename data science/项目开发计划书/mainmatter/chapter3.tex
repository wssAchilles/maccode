\chapter{技术实施与部署方案}

\section{技术栈选型}

\subsection{技术选型原则}

本项目的技术选型遵循以下原则：
\begin{enumerate}
    \item \textbf{成熟稳定}：优先选择经过工业验证的技术，降低技术风险；
    \item \textbf{云原生友好}：支持容器化和无服务器部署，便于弹性伸缩；
    \item \textbf{性能优先}：在满足功能需求的前提下，优化运行效率。
\end{enumerate}

\subsection{前端技术详述}

\subsubsection{Flutter Web 选型论证}

Flutter Web 相较于传统Web框架（React、Vue）具有以下优势：

\begin{enumerate}
    \item \textbf{渲染一致性}：Flutter使用自研的Skia渲染引擎，在不同浏览器上呈现效果完全一致，避免了CSS兼容性问题；
    \item \textbf{高性能图表}：配合fl\_chart库，可实现60fps的流畅动画，适合实时数据可视化场景；
    \item \textbf{代码复用}：未来可以低成本扩展至移动端（iOS/Android）。
\end{enumerate}

\subsubsection{Gurobi 求解器集成}

Gurobi是业界领先的数学优化求解器，本项目通过以下方式集成：

\begin{enumerate}
    \item \textbf{许可证管理}：使用WLS（Web License Service）支持云端部署，无需物理机器绑定；
    \item \textbf{延迟初始化}：仅在首次调用优化接口时初始化Gurobi环境，节省启动时间；
    \item \textbf{环境复用}：使用上下文管理器确保Gurobi环境正确释放，避免许可证泄露。
\end{enumerate}

\subsection{Docker 开发环境}

为确保开发环境一致性，项目提供了Docker Compose配置：

\begin{lstlisting}[caption=docker-compose.yml 核心配置]
services:
  backend:
    build: ./back
    ports: ["8080:8080"]
    environment:
      FLASK_ENV: development
      GRB_WLSACCESSID: ${GRB_WLSACCESSID}
    volumes: ["./back:/app"]

  frontend:
    build: ./front
    ports: ["8000:80"]
    depends_on: [backend]
\end{lstlisting}
