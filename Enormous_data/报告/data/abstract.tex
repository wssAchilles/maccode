\begin{abstract}
本文围绕电商用户行为数据分析课题，构建了基于 Docker ARM64、Hadoop HDFS/YARN 与 Spark 的本机实验集群。系统完成原始 Kaggle 行为数据采样、HDFS 输入、Spark SQL 清洗、推荐/关联/异常等分析模块、质量门禁、缓存发布和前端 Ops 展示。实验对比 local、YARN-only、AQE、算法限流和 Parquet 输入，证明仅接入 YARN 不能自动解决性能与内存问题，必须结合 SQL 优化、数据布局和 driver collect 收敛。
  \thusetup{
    keywords = {Hadoop YARN, Spark SQL, Docker ARM64, 电商行为分析, 内存优化, Benchmark},
  }
\end{abstract}

\begin{abstract*}
This report presents a Docker-based ARM64 Hadoop YARN and Spark experimental system for ecommerce behavior analytics. The project covers Kaggle data sampling, HDFS input, Spark SQL cleansing, recommendation, affinity, anomaly analysis, quality gates, cache publishing, and frontend Ops evidence. Benchmarks compare local Spark, YARN-only, AQE, algorithm guards, and Parquet input, showing that YARN alone does not solve memory and performance risks. Spark SQL tuning, data layout, bounded driver collection, and benchmark evidence are required.
  \thusetup{
    keywords* = {Hadoop YARN, Spark SQL, Docker ARM64, Ecommerce Analytics, Memory Optimization, Benchmark},
  }
\end{abstract*}
